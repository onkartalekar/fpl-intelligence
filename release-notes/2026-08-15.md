# 2026-08-15 -- Streamlined UI and improved performance elevate user experience!

Today's updates bring a cleaner interface and faster performance to our fantasy football decision-support dashboard. Significant UI changes eliminate redundant input fields and ensure clarity in information display, while backend improvements enhance processing speed and error handling, providing a smoother user experience.

- **[Fix]** Remove redundant transfer input fields -- The 'Confirmed free transfers' and 'Free transfers gameweek' inputs have been removed for a cleaner user experience.
- **[Fix]** Enhance error logging for better reliability -- Improved error logging by capturing client details and suppressing excessive error messages during disconnections.
- **[Feature]** Eliminate duplicate risk profile selectors -- The interface now features a single risk profile selector in the Weekly decision section for a more streamlined user experience.
- **[Feature]** Implement structured JSON logging -- API access logs are now formatted in structured JSON for better analysis and monitoring.
- **[Fix]** Improved timeout error handling -- Timeouts now log as concise messages instead of full tracebacks to reduce clutter.
- **[Chore]** Add CI workflow for testing on PRs -- A new CI workflow has been added to automatically run tests on every pull request, enhancing code stability.
- **[Chore]** Implement parallel testing -- Tests can now be executed in parallel, significantly decreasing the time needed to run the suite.
- **[Feature]** Support for multiple free transfers -- Users can now evaluate strategies for up to the maximum allowed free transfers in a gameweek.
- **[Fix]** Recalibrate chip thresholds for accuracy -- Updated thresholds for wildcard and freehit chips for better performance reporting based on player profiles.
- **[Fix]** Mute reference label for benchmark -- The benchmark reference label has been visually muted to avoid confusion with recommended picks.
