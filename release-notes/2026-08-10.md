# 2026-08-10 -- Enhancements galore: better communication, improved usability, and robust defense mechanisms.

This release introduces a sleek HTML email template for deadline reminders, ensuring enhanced clarity and visual consistency. Users can now reach out effortlessly through a dedicated 'Contact Us' feature, complete with local log durability and email capabilities. Additionally, several functional improvements and documentation updates ensure the dashboard remains intuitive and user-friendly.

- **[Feature]** Revamped deadline reminder emails -- Now features a visually appealing HTML format alongside the traditional plain text for better clarity.
- **[Docs]** Environment variable documentation added -- A new section in README.md details all relevant environment variables for easier configuration.
- **[Feature]** Cloud hosting implementation -- Dashboard can now be hosted on the cloud, enhancing accessibility.
- **[Chore]** New operational skills added -- Introduced skills for filing issues and merging pull requests efficiently.
- **[Fix]** Cooldown and timeout for API refresh -- Implemented rate limiting and connection timeout for /api/refresh to improve stability.
- **[Fix]** Seed file access corrected -- Resolved issue causing critical seed files to be unreachable when using mounted volumes.
- **[Fix]** Updated lead-time picker interface -- Replaced raw radio inputs with a styled option tab pattern for a more consistent look.
- **[Feature]** Empty-state panels for profile-required tabs -- Decision Center and Model Performance now guide users to setup their profiles when absent.
- **[Feature]** Introduction of Release Notes file -- Users can now access a summary of features in the newly created RELEASE_NOTES.md.
- **[Docs]** Test skip exception documented -- Clarified documentation for skipping tests related to Markdown-only changes.
- **[Feature]** New Contact Us feature enabled -- Users can now submit feedback or inquiries directly through a new tab, enhancing support.
